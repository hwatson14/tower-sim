# R61 Module Unique Effect Wiring Audit

All 24 module unique scalar effects now have a canonical `mechanic_param::module.*` destination and a contributor mapping. Assist-slot behavior differs by value type: count-style uniques use assist rarity-cap values without extra count scaling; all other scalar uniques use assist rarity-cap selection plus assist-efficiency scaling. Singularity Harness is additionally routed into `mechanic_param::bot.global.range_bonus_m`, and bot canonicals are gated by `capability::bot.*.owned`.
