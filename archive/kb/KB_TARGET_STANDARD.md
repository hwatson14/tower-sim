# KB Target Standard

This package targets **simulator completeness for the intended sim scope** under a truth-first control plane designed for ChatGPT, while also retaining strategy and community layers for theorycraft support.

The package is sufficient for **practical deterministic modelling** without hidden prose interpretation.
It is **not** claiming exact-tick or frame-exact closure across every same-tick edge case.

## Closure gates
A mechanic area is closed when all of the following are true:
1. The mechanic is represented in an active structured surface.
2. Contributor families feeding that mechanic are explicitly routed.
3. Runtime semantics needed to compute it are surfaced in active contracts or package-canon boundary registries.
4. Quantitative values or formulas are supported by bundled provenance or explicit package-canon decisions.
5. Any non-closed rows are explicitly classified as accepted boundaries or out-of-scope edges rather than guessed.

## Knowledge-role rule
This KB serves multiple ChatGPT tasks, so every retained surface should fit one of these roles:
- canonical mechanics
- canonical contract
- package canon
- boundary policy
- strategy guidance
- community signal
- provenance grounding
- explanatory secondary
- derived non-primary

## Input-family rule
Not every simulator-relevant family is a global ladder.
Some families are account-state input registries rather than universal game tables.
These include relic, player_stuff, theme_song, unlock, and externalized vault bonuses.

For these families, simulator completeness requires:
- a canonical input registry surface
- explicit contributor routing
- explicit semantic and unit expectations
- no invented per-account values inside the frozen KB

## Canonical package decisions
- EP-backed module main-effect totals are accepted package canon
- Wall Fortification unlock is package canon at Tier 14 / Wave 60
- broader same-tick micro-precedence is intentionally out of scope except for thorns-after-damage
- 17 tournament BC rows are accepted unknown-to-community boundaries
