# Workshop System

## Core structure
Workshop owns permanent tower upgrades purchased with Coins between rounds and temporary in-run upgrades purchased with Cash during a run.

## Sections
Workshop is divided into three main branches:
- attack
- defense
- utility

Enhancements mirror the same branch split and are coin-funded permanent multipliers layered on top of core workshop progression.

## Canonical quantitative surfaces
- `kb/workshop/tables/workshop-values.csv`
- `kb/workshop/tables/enhancements-values.csv`

## Interpretation rules
- Effective Paths workbook exports are the strongest quantitative ladder source in this package for workshop values.
- Enhancement tables should not be collapsed into the same concept as base workshop ladders.
- Free-upgrade interactions, wave-skip interactions, and battle-condition interactions are separate semantic layers and should not be baked into the base ladder tables.
