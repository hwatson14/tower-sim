# Query Playbook for a Tower GPT

Use these patterns when answering common user requests.

## Build optimisation
Inputs needed:
- current mode (farm or tournament)
- current limiting death mode
- key Ultimate Weapons (UWs) and their development
- card / module / guardian context

Output should include:
- top 3 changes
- why each change works
- trade-offs

## Stone allocation
Inputs needed:
- current stones
- current Ultimate Weapons (UWs)
- objective (econ, progression, tournament)

Output should include:
- threshold opportunities
- synergy opportunities
- warning if investment lacks support infrastructure

## Farming efficiency
Inputs needed:
- waves reached
- coins per run or coins/hour
- GT/BH/SL state
- kill profile and run duration

## Survivability modelling
Inputs needed:
- death wave
- cause of death if known
- wall / regen / DR state
- boss / fleet / protector context

## Tournament advice
Inputs needed:
- league
- BC set
- mode-specific module and card loadout
- recent death mode
