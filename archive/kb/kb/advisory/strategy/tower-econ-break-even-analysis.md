# Tower Economy Break-Even Analysis

Purpose:
Provide comparison framework between sync reductions, bot medals, and card masteries.

## 1. Synced GT/DW cooldown cuts
Chat modelling suggested synced cooldown reductions offer meaningful but not automatically dominant economy value.
Proper comparison requires corrected interpretation of wiki cooldown cost tables plus actual source-share data.

## 2. Coins Mastery
Direct all-coins style effect if equipped.
Potentially strong on pure stone efficiency, but real cost also includes mastery lab time and coin cost.

## 3. Critical Coin Mastery
Only beats broad econ alternatives if Crit Coin is a meaningful share of total income.

## 4. Extra Orb Mastery
Only beats broad econ alternatives if orb-derived coin share is large.

## 5. Enemy Balance Mastery
Can be important if coin throughput is spawn-limited and extra elite/body generation converts into actual kills in coin windows.

## 6. Decision principle
The real comparison is:
upgrade cost -> expected delta in total objective -> efficiency
