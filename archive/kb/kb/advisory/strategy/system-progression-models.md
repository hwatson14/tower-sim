# System Progression Models

This file stores the distilled progression framing that was previously added in KB v8.

## Early game
Dominant tools:
- thorns
- orbs
- knockback
- HP / defense scaling

Framing:
- eHP-style survivability dominates when enemy damage is still manageable.

## Mid game
Transition pressures:
- Protectors
- elites
- higher enemy HP
- reduced reliability of orb-only control

Framing:
- hybrid survivability + damage setups emerge.

## Late game
Dominant requirement:
- kill enemies before contact

Common power layers:
- Ultimate Weapons
- card masteries
- damage labs
- stronger modules

## Farming meta
Core overlap target:
- Golden Tower
- Black Hole
- Spotlight

Reason:
- Multiplicative coin stacking rewards kill timing inside overlapping bonuses.
