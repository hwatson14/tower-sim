# Self-contained package policy

This frozen KB is self-contained.

Meaning:
- No external sim repo, spreadsheet, or sidecar package is required to use the active canonical surfaces.
- Upstream sources may still be cited for provenance and evidence tier classification.
- Any imported source data needed for the current frozen KB must exist inside this package.

Practical rule:
- Treat this package as the canonical working base.
- Reopen only when new evidence is intentionally imported and internalized.
