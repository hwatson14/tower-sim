# Perk runtime contract

Perks are run-scoped choices. Domain ownership:
- perk identities and pool weights
- perk selection timing
- perk-lab interaction rules

Runtime rules:
- perks appear on a wave schedule, not continuously
- wave requirement modifications stack through the documented formula family
- auto-pick and ban-perk systems belong to perk governance, not generic labs
- ultimate-weapon-specific perks are eligible only when their named Ultimate Weapon is already unlocked for the current account/run state
- the Random UW unlock perk is a special unlock event; it must not make every UW-specific perk globally eligible
