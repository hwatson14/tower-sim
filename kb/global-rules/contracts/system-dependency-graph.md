# System Dependency Graph

This file records high-level dependency relationships between systems.

## Player-side
- labs -> modify workshop scaling and specialized mechanics
- cards -> modify runtime stats and utility behavior
- modules -> modify stats and mechanics
- perks -> temporary run modifiers
- ultimate_weapons -> active combat / economy abilities
- guardians -> persistent scaling layer

## Enemy-side
Difficulty depends on:
- enemy scaling
- heat mechanic
- elite spawn rules
- battle conditions
- tournament pacing
- fleets / special interactions

## Economy-side
Coin output depends on:
- kill timing
- Golden Tower / Black Hole / Spotlight overlap
- cleanup speed
- anti-control exceptions
