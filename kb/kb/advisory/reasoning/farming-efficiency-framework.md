# Farming Efficiency Framework

## Core metric
The most useful farming metric is not raw coins per run but coins per real-world hour.

Conceptual model:
coins_per_hour = coins_per_wave × waves_per_hour

Cells-per-hour should be modelled separately because the best coin setup is not always the best lab-speed setup.

## Main drivers
- run length
- kill density
- GT uptime
- BH uptime and clustering
- Spotlight coin exposure
- card and module economy multipliers
- enemy density modifiers

## Important interactions
### More enemies
Can be good for farming if kill conversion remains high.

### Longer runs
Are only better if late-run slowdown does not destroy coins/hour.

### Sync value
GT × BH × SL overlap is often more important than raw isolated bonus.

## Failure modes
- overbuilding survival and losing coins/hour
- killing outside economy windows
- poor BH coverage / duration
- insufficient Spotlight coverage
- ignoring cell yield trade-offs
