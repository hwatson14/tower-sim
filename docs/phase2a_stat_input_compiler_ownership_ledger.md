# Phase 2A — `compilers/stat_input_compiler.py` ownership ledger

Change classification: **Cleanup only**.

## Scope note

This ledger classifies every meaningful top-level helper, constant block, and in-function logic section that participates in stat-input compilation or query preparation inside `compilers/stat_input_compiler.py`. It is an ownership artifact for Phase 2A only; it does **not** imply Phase 2B seam extraction has already happened.

## Canonical owner model applied

- **Inputs** owns account/input compilation, value materialization, preset selection, and `StatInput` row emission.
- **Query Engine** owns query-governed published stat surfaces, routing registries, destination binding policy, state-mode publication policy, and compatibility-preserving published-surface preparation.
- Compatibility entrypoints inside `compilers/stat_input_compiler.py` are treated as temporary hosting surfaces, not canonical long-term owners.

## Regression anchors for risky move/split candidates

- **State-mode policy extraction** must preserve alias normalization, support payload shape, and row filtering semantics for `start_of_run` vs `max_progression`. Primary anchor: `tests/test_state_mode_contracts.py`.
- **Lab/workshop/relic/vault/bot/guardian/UW/module splits** must preserve current `compile_stat_inputs()` row counts, destination IDs, contributor IDs, and notes for the existing compatibility entrypoint consumers in the incremental/query planner/runtime executor stack.
- **Cards/perks/enhancements/theme-song/player-meta moves** are risky because they are already mostly published-surface logic; extraction must preserve split fan-out rows, capability coercions, and free-upgrade/card/perk special cases.
- **Perk extraction** specifically must preserve Standard Perk Bonus and Improve Trade-off Perks semantics anchored by `tests/test_perk_scaling.py` and the smoke imports that assert helper availability.
- **Module extraction** must preserve assist-rarity/main-effect behavior and manual unique splits anchored by `tests/test_bot_module_uniques_and_unlocks.py`.
